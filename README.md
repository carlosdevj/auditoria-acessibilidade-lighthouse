# Auditoria de Acessibilidade com Lighthouse

Página acadêmica para apresentação da auditoria de acessibilidade realizada com o Lighthouse nos sites Amazon Brasil, SHEIN Brasil e no site desenvolvido pelo grupo.

## GitHub Pages

https://carlosdevj.github.io/auditoria-acessibilidade-lighthouse/

## Recursos da página

- HTML semântico
- Layout responsivo
- Navegação por teclado e foco visível
- Texto alternativo e atributos ARIA
- Tema claro e escuro
- Modo de alto contraste
- Controle de tamanho da fonte
- Preferências de acessibilidade persistidas no navegador
- Dinâmica interativa para apresentação

> O link público dos relatórios do Lighthouse deve ser configurado na constante `REPORTS_URL` do `index.html` quando estiver disponível.
